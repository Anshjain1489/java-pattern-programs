# ☕ Java Pattern Programs

A collection of Java pattern programs created to practice nested loops, logical thinking, and problem-solving skills.

This repository contains beginner-friendly star patterns, number patterns, and other commonly asked programming exercises.

## 📚 Programs Included

1. Right-Angled Triangle
2. Inverted Triangle
3. Pyramid Pattern
4. Diamond Pattern
5. Hollow Square
6. Number Triangle
7. Floyd's Triangle

## 💻 Technologies Used

- **Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 🧠 Concepts Covered

- `for` loops
- Nested loops
- Conditional statements (`if-else`)
- Increment and decrement operators
- Rows and columns
- Spaces and pattern alignment
- Problem-solving and dry runs

## ▶️ How to Run

### 1. Install Java

Install the Java Development Kit (JDK) on your computer.

### 2. Clone the Repository

```bash
git clone https://github.com/Anshjain1489/java-pattern-programs.git
```

### 3. Open the Project

```bash
cd java-pattern-programs
```

### 4. Compile a Java Program

For example, to compile the right-angled triangle program:

```bash
javac -d . patterns/RightTriangle.java
```

### 5. Run the Program

```bash
java patterns.RightTriangle
```

**Note:** The examples use the `patterns` package. Compile from the project root directory. Repeat the commands with the appropriate filename and class name for other programs.
